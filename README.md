> A curated list of resources for modern C++ (C++11 through C++23/C++26), high-performance build systems, package managers, concurrency frameworks, template metaprogramming, and graphics engines.

C++ is a high-performance, statically typed systems programming language offering fine-grained memory management, zero-cost abstractions, object-oriented primitives, compile-time metaprogramming (`constexpr`/`consteval`), concepts, and multi-threading models. It powers operating system kernels, game engines, real-time audio drivers, financial trading platforms, and low-latency network backends. This list is intended for systems software engineers, performance engineers, game developers, graphics programmers, and C++ software architects.

## Compilers, Build Systems & Package Managers

Toolchains, build generators, static linkage systems, and dependency managers for C++ codebases.

- [CMake](https://github.com/Kitware/CMake) — Cross-platform, open-source build system generator widely adopted across modern C++ ecosystems.
- [Ninja](https://github.com/ninja-build/ninja) — Small build system focusing on speed, designed to execute files generated by higher-level build tools.
- [vcpkg](https://github.com/microsoft/vcpkg) — C++ library manager for acquiring and managing native libraries on Windows, Linux, and macOS.
- [Conan](https://github.com/conan-io/conan) — Decentralized, open-source C and C++ package manager built for multi-platform development pipelines.
- [Meson](https://github.com/mesonbuild/meson) — Open-source build system designed to be fast, user-friendly, and capable of handling complex C++ projects.

## Asynchronous Concurrency & Networking

High-performance networking libraries, coroutine engines, lock-free data structures, and event loops.

- [Asio](https://github.com/chriskohlhoff/asio) — Cross-platform C++ library for network and low-level I/O programming providing an asynchronous model.
- [uWebSockets](https://github.com/uNetworking/uWebSockets) — Ultra-fast, memory-efficient WebSocket and HTTP server implementation built for C++.
- [folly](https://github.com/facebook/folly) — Facebook's open-source library of high-performance C++17 components, lock-free queues, and concurrency utilities.
- [Seastar](https://github.com/scylladb/seastar) — Advanced, open-source C++ framework for high-performance server applications using shared-nothing thread-per-core architectures.
- [tbb (OneTBB)](https://github.com/oneapi-src/oneTBB) — Intel's Threading Building Blocks library simplifying parallel processing and task scheduling.

## Serialization & Data Interchange

Fast JSON parsers, binary wire formats, protocol buffers, and reflection engines.

- [nlohmann/json](https://github.com/nlohmann/json) — Intuitive, single-header C++20 JSON parser designed to feel like a first-class language feature.
- [FlatBuffers](https://github.com/google/flatbuffers) — Cross-platform serialization memory-efficient library allowing direct access to serialized data without unpacking.
- [Protocol Buffers (protobuf)](https://github.com/protocolbuffers/protobuf) — Language-neutral, platform-neutral extensible mechanism for serializing structured data.
- [fmt](https://github.com/fmtlib/fmt) — Open-source formatting library providing a fast and type-safe alternative to C stdio and C++ iostreams.

## Graphics & Game Development

Low-level graphics abstractions, 3D rendering engines, real-time physics, and spatial mathematics.

### Rendering Engines & Frameworks

- [bgfx](https://github.com/bkaradzic/bgfx) — Cross-platform, graphics API-agnostic rendering library supporting Vulkan, Direct3D, Metal, and OpenGL.
- [Magnum](https://github.com/mosra/magnum) — Lightweight and modular C++17/C++20 graphics engine for games and scientific visualizations.
- [raylib-cpp](https://github.com/RobLoach/raylib-cpp) — C++ object-oriented wrapper around the simple raylib game programming library.

### Audio & Physics Libraries

- [PhysX](https://github.com/NVIDIA-Omniverse/PhysX) — High-performance real-time multi-threaded physics engine developed by NVIDIA.
- [Box2D](https://github.com/erincatto/box2d) — 2D physics engine for games designed to simulate rigid bodies and continuous collisions.

## Testing & Static Analysis

Unit test frameworks, mocking systems, dynamic sanitizers, and static code checkers.

- [Catch2](https://github.com/catchorg/Catch2) — Modern, C++-native test framework for unit testing, TDD, and BDD assertions.
- [GoogleTest](https://github.com/google/googletest) — Google’s C++ testing and mocking framework providing rich assertions and test runner infrastructure.
- [doctest](https://github.com/doctest/doctest) — Fastest feature-rich C++ single-header testing framework for fast compilation times.
- [Clang-Tidy](https://clang.llvm.org/extra/clang-tidy/) — LLVM-based C++ linter tool designed to diagnose and fix programming errors, style violations, and modernization anti-patterns.
